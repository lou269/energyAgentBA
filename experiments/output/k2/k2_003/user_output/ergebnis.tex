\subsection*{Hinweise}
\begin{itemize}
\item Ebene 1 prüft, ob ein Modell die Regeln aus dem Prompt nachvollzieht. Der Prompt wurde auf denselben Fällen verbessert, die Quoten begründen deshalb nur die Modellwahl und belegen nicht das Ziel von 80 \% richtiger Klassen (dafür E2)
\item wenige Fälle: ein Fall sind mehrere Prozentpunkte, eine Klasse hängt teils an einem einzigen Fall
\item Macro-F1: Mittel der F1-Werte über die Klassen, die als erwartete Klasse vorkommen
\item Grounding: Anteil der für den Fall erwarteten Felder, die das Modell als Beleg zitiert. Die Regel zitiert keine
\item Ebene 2, erkannt: erwartete Klasse an einem Tag, an dem nur das Szenario den Vorfilter öffnet (gepaart mit dem Kontrolllauf desselben Modells)
\item Ebene 2, Abweichungstage: gleiche Art und gleicher analysierter Tag, Regel gegen Modell. Nach einem Zurücksetzen an verschiedenen Tagen laufen die Reihen auseinander, spätere Abweichungen können daraus folgen
\item Zeit: gemessen auf dem Rechner des Laufs, nur zum Vergleich der Modelle untereinander
\item Textprüfung: Verstoß heißt, ein Steuerungswort oder eine Zahl, ein Datum oder eine Uhrzeit steht im Text, aber nicht im State des Falls. Zahlwörter („sechs Wochen“) findet sie nicht. Die Fensterlängen 7 und 28 aus der Skalenbeschreibung im Prompt gelten als erlaubt
\item Beleg fehlt: der Prompt verlangt je Klasse bestimmte Pfade (new\_\allowbreak{}pattern: sustained\_\allowbreak{}drift, Streaks, peak und low: level, direction, absence: level, Kalendereintrag, measurement\_\allowbreak{}error: Flag). Geprüft wird gegen die eigene Klasse des Modells, nicht gegen die erwartete. Ebene 1 wird nur für Läufe geprüft, die den State der Fälle in der Antwortdatei speichern, ältere Läufe haben in der Tabelle 0 Antworten
\item Antworttexte, Abweichungstage, Erkennung je Szenario und Auffälligkeiten der Textprüfung stehen als CSV im Ordner des Laufs (answers\_\allowbreak{}single, answers\_\allowbreak{}sequence nur vom Produktivmodell, result\_\allowbreak{}text\_\allowbreak{}findings, sequence\_\allowbreak{}events)
\end{itemize}
